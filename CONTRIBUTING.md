# Contributing

Thanks for helping make this list better. New prompts, fixes and better wording are all welcome.

## Adding a prompt

1. Open a pull request that adds your prompt to the matching file in [`prompts/`](prompts/) (and to the README only if it is clearly one of the best in its category).
2. Follow the existing format: a short `###` title, the prompt in a ```` ```text ```` code block, and a negative prompt if it helps.
3. Write in clear English. Use square-bracket placeholders such as `[PRODUCT]`, `[BRAND]` or `[NAME]` for anything the user should replace.
4. Say which tool(s) you tested it in (for example ChatGPT, Gemini, Midjourney, Kling or Runway) in the pull request description.

## Quality bar

- Original and useful: no near-duplicates of existing prompts.
- Keeps the person's identity when a reference photo is used; changes only what the prompt is about (outfit, light, background, style).
- Describes styles and scenes in your own words. No trademarks, logos, real celebrities or copying a living artist's work.

## Not accepted

- Prompts involving real people without their consent, impersonation or deepfakes.
- Sexual or nude content of anyone, and anything involving minors in an unsafe way.
- Prompts for fake IDs, official documents, scams or misleading product listings.
- Links to paid, affiliate or spam sites.
